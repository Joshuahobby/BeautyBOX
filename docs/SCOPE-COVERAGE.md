# BeautyBOX scope and optional-item coverage

Reviewed 16 November 2026 against the current code, the owner's conversation decisions and the uploaded product brief, FSD, UX specification, brand foundation and preparation checklist. Uploaded documents remain unchanged. Their original proposals are context; subsequent owner decisions take precedence, including Silverback Mall and RWF 250/km beyond the first 3 km.

Status: **implemented** means present and locally tested; **mock-tested** distinguishes provider simulation from live evidence; **blocked** names missing access or business evidence; **deferred** names a future feature rather than implying it is built. This audit does not approve release or introduce independent sellers.

## Release inputs that code review cannot supply

Real stock/counts/costs, approved photography/copy, contacts/hours, service window, rider arrangements, parcel measurements, legal/privacy/receipt/tax/language approvals, production merchant/network/refund evidence, real-device/assistive-technology review and hosted recovery evidence still need their respective owners. Staff password-reset session revocation, custom SMTP, unused-photo retention and Supabase account-advisor items remain in `RELEASE-CHECKLIST.md`/`PROGRESS.md`. This review does not silently approve any of them.

Booking, CRM, independent vendors, rider GPS, AI, loyalty and other later-business-plan capabilities are future phases. Reviewing their status does not mean implementing or approving them under a storefront audit.

## Reproducible checks

`npm run verify`; `npm run test:integration`; `npm run test:e2e`; `npm run audit:optional`; `npm run delivery:check-google` (zero-request default); `npm run ops:drill -- --source beautybox_test` (local only). Fresh audit results, accepted screenshots and the detailed findings are linked from `DETAIL-AUDIT.md`. An optional readiness result is never presented as a passed live test.
